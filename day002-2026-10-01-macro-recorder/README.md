# Day 002 · 매크로 녹화기

마우스·키보드 동작을 녹화해서 원하는 횟수만큼 다시 실행하는 윈도우 데스크톱 앱입니다.
Python + tkinter + [pynput](https://pynput.readthedocs.io/)으로 만들었습니다.

## 실행

`run.bat`을 더블클릭하면 됩니다. 처음 실행할 때 가상환경을 만들고 `pynput`을 설치합니다.

직접 실행하려면:

```bash
python -m venv .venv && .venv/Scripts/python.exe -m pip install -r requirements.txt
```
```bash
.venv/Scripts/python.exe main.py
```

## 단축키

창이 다른 프로그램에 가려져 있어도 동작합니다.

| 키 | 동작 |
|----|------|
| `F9` | 녹화 시작 / 중지 |
| `F10` | 재생 시작 / 중지 |
| `Esc` | 즉시 중지 (재생 대기 중이면 취소) |

`F9` `F10` `Esc`는 녹화에 포함되지 않습니다.

## 기능

- **녹화**: 마우스 이동·클릭·휠, 키 누름·뗌을 시간 간격까지 그대로 기록
  - 마우스 이동은 0.02초 간격으로 추려서 기록하고, 체크를 끄면 클릭 지점만 남아 파일이 가벼워짐
- **재생**: 반복 횟수(또는 무한), 0.25~4배속, 반복 사이 간격, 시작 전 3초 대기
- **저장**: `macros/` 폴더에 JSON으로 저장하고 목록에서 불러오거나 삭제
- **이벤트 목록**: 녹화된 동작을 시간과 함께 한 줄씩 확인
- 재생이 중간에 멈춰도 눌린 키·마우스 버튼을 모두 떼어 놓음

## 파일 구성

```
main.py          tkinter 화면과 전체 흐름
recorder.py      pynput 리스너로 입력 녹화
player.py        별도 스레드에서 이벤트 재생
events.py        이벤트 직렬화 규칙과 설명 문구
storage.py       macros/*.json 저장·불러오기
```

## 저장 형식

```json
{
  "name": "매크로1",
  "created_at": "2026-10-01T15:04:21",
  "duration": 3.42,
  "events": [
    { "dt": 0.0, "type": "move", "x": 820, "y": 410 },
    { "dt": 0.12, "type": "click", "x": 820, "y": 410, "button": "left", "pressed": true }
  ]
}
```

`dt`는 앞 이벤트로부터 흐른 시간(초)입니다.

## 한계

- 좌표를 그대로 재생하므로, 녹화할 때와 **창 위치나 해상도가 다르면 엉뚱한 곳을 클릭**합니다.
- 관리자 권한으로 실행되는 프로그램 위에서는 입력이 전달되지 않습니다. 그 경우 이 앱도 관리자 권한으로 실행해야 합니다.
- 게임 등 입력 보호가 걸린 프로그램에서는 동작하지 않을 수 있습니다. 약관을 위반하지 않는 범위에서 사용하세요.
- 재생 중에는 마우스·키보드가 자동으로 움직입니다. 멈추려면 `Esc`를 누르세요.
